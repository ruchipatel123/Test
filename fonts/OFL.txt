The file `montserrat-700-stroke.woff2` in this folder is a MODIFIED copy of
Montserrat Bold: contour overlaps have been removed (fontTools removeOverlaps)
and the character set subset to Latin. The modification exists so the font can
be rendered as an outline (-webkit-text-stroke) without the internal seams that
overlapping contours produce. No other change was made.
